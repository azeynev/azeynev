$$\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}, \quad \sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}$$ $$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$
Алгоритмично моделиране (Python) 
import math

def monte_carlo_pi(n: int) -> float:
    """Числена оценка на числото Пи."""
    inside = sum(
        1 for i in range(n)
        if ((i * 0.6180339) % 1)**2 + ((i * 0.381966) % 1)**2 <= 1
    )
    return 4 * inside / n

print(f"Приближение: {monte_carlo_pi(10000):.5f}")
