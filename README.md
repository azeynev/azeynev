### 🏆 Избрани разработени системи (Projects)

#### 📊 [Училищен Барометър (School Master Edition)](https://azeynev.netlify.app)
> Веб приложение за цялостен методически и количествен анализ на успеваемостта по МО и випуски, изчисляване на интегрален индекс (0–100) и експорт към Word/JSON.

* **Технологии:** Tailwind CSS, Responsive Iframes, FontAwesome.
